# dsh-ca-image-console

把 dsh-ca-image 的控制台链接放进设置 → 插件区，省得记网址

## 项目结构

```
client.js
cordis.patch.yml
icon.svg
index.js
locale/
locale/en.json
locale/zh.json
package.json
```

## 安装

```bash
npm install
```

## 使用

这是一个 DSH 插件 / 项目，按项目内脚本或文档使用。

## DSH 安装 / 卸载

### 安装

```bash
dsh plugin --profile web add dsh-ca-image-console
```

### 卸载

```bash
dsh plugin --profile web remove dsh-ca-image-console
```
